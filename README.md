# val_player · 无畏契约选手生涯模拟器

单人文字生涯模拟：你是一名虚构的无畏契约新人选手，在由真实 VCT 选手和俱乐部构成的世界里，
从替补打到首发、从 Challengers 打到 Champions。

- 引擎与真实数据来自 [Val_Manager](https://github.com/WeijieCao77/Val_Manager)（无畏契约电竞经理）——逐回合比赛模拟、VCT 日历、524 名真实选手。
- 选手视角的玩法与赛场外系统来自 [LOL_breaker](https://github.com/WeijieCao77/LOL_breaker)（破晓 · LoL 选手生涯模拟器）——周与行动点、临场决策、首发竞争。

总体方案见 [策划稿-总体方案-v0.md](./策划稿-总体方案-v0.md)。

## 当前状态：可玩 demo（P0 + 一部分 P1）

已经能做的：

- **开档**：ID、赛区、位置、20 点天赋分到 8 维，选一家一级俱乐部（或随机，弱队更愿意赌新人）。
- **周循环**：每周 8 行动点——枪法训练、复盘、道具与跑图、排位、跟队训练赛、队友双排、直播、休息；
  推进一周时世界按天走，遇到自己队的比赛停下来打。
- **比赛**：Val_Manager 的逐回合引擎原样跑；你在场上时每张图会遇到 2–3 次要拿主意的时刻
  （手枪局、先手、经济局、残局、落后暂停、赛点、加时……），每次决定后立刻显示本图赢面的变化；
  终场给你的 K/D/A、ACS、评分、队内排名和整场的决策账本。快进走同一条路径。
- **首发竞争**：教练每周按「综合 × 样本量折扣 × 状态 × 信任」重排名单；替补可以向同位置首发发起对位挑战，
  攒够资本得到两场试用期；试用期打不出来回替补，连着三场全队最差会被换下。
- **成长**：训练收益沿用引擎公式（年龄、疲劳、士气、教练、设施、上限空间），外加心态/体质两个体质型属性。
- **赛季**：完整 VCT 日历、AI 转会、老化、退役；赛季末自动记生涯、自动续约。
- **存档**：浏览器自动存档，刷新可继续。

还没做（见策划稿分期）：合同谈判、转会与试训、粉丝/直播的完整系统、事件与特质、托管、成就与结局、职业前阶段。

## 本地运行

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # 产物在 dist/，纯静态
```

`/manager` 与 `/cards` 仍然可以打开原来的经理模式和卡牌模式，存档互不干扰。

## 无头机器人

```bash
npx tsx scripts/bot_me.ts [赛季数=2] [种子=7] [赛区=China] [位置=决斗者] [俱乐部id]
```

机器人走的是和界面完全一样的 `setPlan / doDuel / advanceWeek / MeMatch` 路径，跑完打印每季出场、胜场、ACS、成长与节点统计。
每加一段内容都要跑一次，看数字有没有漂。

## 代码结构

```
src/engine/            Val_Manager 的引擎（match / season / training / transfer / bonds / trust …），几乎未改
src/engine/me/         选手层
  career.ts            建档：把「我」放进一支真实俱乐部的替补席
  week.ts              周循环：行动点、推进、周结算、赛季末
  growth.ts            我的训练收益、心态/体质
  coach.ts             教练 AI：选人、对位挑战、试用期、换下
  nodes.ts             临场决策池与成功率
  matchplay.ts         逐回合驱动一场比赛并在节点处停下；快进同路径
  auto.ts              推荐安排（也是机器人的一周）
src/PlayerGame.tsx     壳子；src/ui/me/*  开档 / 本周 / 比赛 / 我的 / 队伍 / 日志
scripts/bot_me.ts      无头整局
```

对引擎的改动只有两处：`match.ts` 的 `MapSim` 加了一个每回合衰减的 `nudge`（节点的摆动写在这里），
`types.ts` 的 `GameState` 加了 `me` 字段。
